# MARCH 화면과 디자인

**저장 → 검색 → 근거 확인** 순서가 한눈에 읽히는 한국어 개인 보관함. [2026-INTHON의 Malo 프런트엔드](https://github.com/2026-INTHON/frontend/tree/00d8cadf46f55115fe48c9efeb2586bf6ccf90b8)를 참고했다.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| 캔버스 | `#F3F2EE` | 베이지 배경 |
| 카드 | `#FFFFFF` | 보관 항목·입력·상세 |
| 잉크 | `#111111` | 본문·선택 탭·키보드 포커스 |
| 라임 | `#D4FF4F` | 링크 저장 같은 주요 행동 |
| 곡률 | 카드 `20px`, 버튼 `28px`, 입력 `12px` | 화면 간 일관성 |
| 타이포 | Noto Sans KR 계열, 제목 `32px`, 본문 `16px` | 설치 환경에 따라 시스템 한국어 sans 사용 |

## 화면별 동작

| 화면 | 배치와 동작 |
| --- | --- |
| 로그인 | 데스크톱은 서비스 소개·서윤 가이드와 계정 입력을 나눈다. 작은 화면은 입력을 먼저 읽을 수 있게 정리한다. |
| 보관함 | 탐색 → 빠른 저장 → 검색·필터 → 목록. 데스크톱은 기본 2열 카드, 좁은 화면은 한 열. 카드와 목록 전환 시 동일한 정렬·필터를 유지한다. |
| 상세 | 데스크톱 모달, 모바일 하단 시트. 확인된 내용·원문 근거·개인 편집값을 나누고 원문 링크를 열 수 있다. |
| 연결 관리 | DM 증명과 웹 최종 승인을 단계별로 표시한다. 연결 해제 시 기존 보관 항목은 남는다. |

서윤은 로그인과 빠른 저장에 등장하는 정적 가이드다. 캐릭터 이미지는 원본 프로젝트의 [에셋 기록](https://github.com/2026-INTHON/frontend/blob/00d8cadf46f55115fe48c9efeb2586bf6ccf90b8/assets/img/char-seoyun.png)을 참고했고 이 문서 패키지에는 포함하지 않았다. 원본의 재배포 권한은 별도 확인 대상이다.

## 상태 표시

저장과 분석은 따로 진행된다. `정리 대기`와 `정리 중`은 기다리는 상태, `정리됨`은 근거 범위를 확인할 수 있는 상태다. `링크만 저장됨`은 원문 미확보, `분석 보류`는 예산 제한, `정리 실패`는 재요청을 검토할 상태다. 오류가 나도 입력값을 보존하고 상태는 텍스트로 읽을 수 있게 한다.
